# Rekap Parkir OCR Next.js (Lengkap dengan Progress %)

Aplikasi pemindai struk parkir otomatis menggunakan Next.js dan Tesseract.js.
Sudah dilengkapi dengan **Progress Bar Real-time (%)**.

## Cara Deploy ke Vercel via GitHub:

1. Download dan extract file ZIP ini.
2. Buat repository baru di **GitHub** dan upload semua file hasil ekstrak.
3. Buka **Vercel**, pilih repository GitHub Anda, lalu klik **Deploy**.
