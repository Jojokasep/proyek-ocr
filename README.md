# Rekap Parkir OCR Next.js

Aplikasi pemindai struk parkir otomatis menggunakan Next.js dan Tesseract.js.

## Cara Deploy ke Vercel via GitHub:

1. Extract file ZIP ini ke komputer/laptop Anda.
2. Push seluruh folder project ini ke repository **GitHub** baru.
3. Buka [Vercel](https://vercel.com) dan hubungkan akun GitHub Anda.
4. Import repository tersebut dan klik **Deploy**.
5. Vercel akan secara otomatis mem-build dan memberikan link domain gratis untuk diakses!
